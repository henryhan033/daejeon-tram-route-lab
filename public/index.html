현재 대중교통 경로는 무료 Transitous API로 조회합니다. 지도 배경은 OpenStreetMap 타일이며 Transitous 경로 API와 별개입니다. 트램 도입 시나리오는 출발지에서 버스를 타고 트램역까지 이동한 뒤 트램으로 환승하고, 하차 후 다시 버스를 타는 경로(버스 → 트램 → 버스)를 우선 탐색해. 도로명 주소와 구 주소(지번 주소) 어느 쪽으로 입력해도 무료 공개 지오코더 여러 검색어 형식으로 함께 조회해. 결과에 두 주소가 실제로 제공되면 둘 다 표시하고, 공개 데이터에 없는 주소 형식은 임의로 만들지 않아. 자동완성 후보에서 정확한 장소를 직접 선택해야 다른 장소로 잘못 연결되는 걸 막을 수 있어.

데이터 출처와 계산 방식

현재 경로 계산: 인증키가 필요 없는 Transitous 공개 API로 현재 대중교통 경로와 소요시간을 조회합니다. 같은 출발지·목적지 요청은 10분 동안 서버 메모리에 캐시합니다. Transitous는 공개 GTFS를 바탕으로 운영되는 커뮤니티 서비스라 대전 노선 제공 범위가 바뀔 수 있습니다.

주소·장소 검색: 별도 API 키 없이 Transitous/MOTIS와 OpenStreetMap(Photon) 공개 검색을 사용합니다. 도로명 주소와 구 주소(지번 주소) 중 어느 형식으로 입력해도 원문 검색어와 대전광역시를 붙인 검색어를 함께 조회하고, 결과를 합쳐 중복을 줄입니다. 제공자가 두 주소 형식을 모두 알려주는 경우에만 둘 다 표시하며, 지번 정보가 없을 때 도로명 주소를 지번 주소인 것처럼 표시하지 않습니다. 주소·장소 데이터에 없는 항목은 검색되지 않을 수 있으므로 후보를 확인한 뒤 직접 선택해야 합니다.

트램 경로: 대전트램 공식 홈페이지의 정거장 명칭을 바탕으로 OpenStreetMap에서 좌표를 근사 검색합니다. 출발지→트램 탑승역과 트램 하차역→목적지는 Transitous에서 각각 조회하며 버스가 포함된 경로를 우선 선택합니다. 따라서 버스 → 트램 → 버스처럼 트램이 중간 이동수단으로 들어갈 수 있습니다. 연결 경로가 없을 때만 가까운 정거장까지 도보 추정으로 대체합니다. 정거장 검색 좌표는 공식 선로 좌표가 아니므로 지도에는 주황색 트램 선형을 표시하지 않습니다. 공식 실시설계 선형 데이터 확보 후에만 선로 레이어를 추가해야 합니다. 거리·시간은 별도 시뮬레이션 계산값입니다. 트램 구간은 표정속도·배차간격·정차시간 가정으로 계산하며 공식 운행시간표가 아닙니다.

비용·인증: 대중교통 경로와 주소·장소 검색은 API 키가 필요 없는 공개 서비스를 사용합니다. Transitous는 커뮤니티 기반 공개 서비스이며 대전 지역의 주소·대중교통 데이터 커버리지에 따라 검색 결과가 다를 수 있습니다. 검색 후보를 직접 선택하지 않으면 경로 계산을 진행하지 않습니다.

유의: 현재 경로는 Transitous 공개 대중교통 API 응답입니다. 지도 배경 타일은 OpenStreetMap에서 제공되며 Transitous 자체 타일이 아닙니다. 트램 도입 후는 출발지→트램역과 트램역→목적지의 대중교통 경로를 별도로 조회해 가운데 가상 트램 구간과 연결합니다. 연결 대중교통 경로가 없을 때만 가까운 정거장까지 짧은 도보 추정으로 대체합니다. 트램 구간은 정거장 좌표와 평균속도·배차간격·정차시간으로 계산한 시뮬레이션이며, 두 개의 현재 시간표 경로를 가상 트램 운행과 동기화한 정밀 시간표는 아닙니다. 동일 출발지·목적지 결과는 메모리에 10분 캐시해 공개 서비스 호출을 줄입니다. 절감 시간은 가정에 따른 비교이며 실측값이나 보장값이 아닙니다. 주소 검색은 도로명 주소·지번 주소 어느 쪽으로 입력해도 Transitous/MOTIS와 Photon/OpenStreetMap을 함께 조회합니다. 원문/대전 지역명 검색 결과를 합쳐 표시하며, 실제로 반환된 지번 주소만 지번이라고 표시합니다. 사용자가 직접 선택한 결과의 좌표를 Transitous 경로 API에 전달합니다. 검색 후보를 선택하지 않으면 자동으로 첫 결과를 사용하지 않습니다. 트램 정거장 좌표는 지도검색 기반 근사치입니다.

## v1.11.8 검증 및 정확도 고지 - `package.json`, `/api/health`, 화면 제목/버전 표기를 1.11.8로 맞췄습니다. - 화면의 주소 좌표 출처는 선택된 지오코딩 결과의 `source` 필드를 사용합니다(항상 Transitous라고 고정 표기하지 않음). - 대전시가 2025년 10월 공개한 45개 정거장 공식 명칭을 UI 표시명에 반영했습니다. 좌표 검색어는 주변 랜드마크 기반이므로 공식 정거장 좌표와 동일하지 않을 수 있습니다. - 지도상의 트램 구간은 OSRM 자동차 도로망 기반 시각화 근사입니다. 실제 트램 선로 정렬이나 공식 실시설계선으로 간주하면 안 됩니다. - 실행 환경에서 외부 Transitous/OSM 서비스 연결이 차단될 수 있으므로, 이 환경에서는 외부 API의 실시간 응답 성공을 보장하지 않습니다.
