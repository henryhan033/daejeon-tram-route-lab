# 대전 트램 경로 실험실 v1.13.7 — 일반 건물 다중 검색

주소·장소 검색은 별도 키가 필요 없는 Transitous/MOTIS, Photon/OpenStreetMap, Nominatim/OpenStreetMap 공개 검색을 함께 사용합니다. 주소 검색과 건물·장소 검색 결과를 합쳐 후보를 보여주므로 특정 건물 하나에만 맞춘 기능이 아닙니다. 원문 주소와 `대전광역시`를 붙인 주소를 병행 검색해 도로명 주소와 구 주소(지번 주소) 중 어느 형식으로 입력해도 후보를 찾도록 했습니다. 현재 대중교통 경로는 Transitous 공개 API로 조회합니다.

## 실행 방법

1. ZIP을 새 폴더에 압축 해제합니다.
2. Node.js 18 이상이 설치되어 있는지 확인합니다.
3. 폴더 안의 `run.bat`을 실행합니다.
4. `run.bat` 창에 표시되는 주소로 접속합니다. 기본 포트는 `3024`이며, 구버전이 켜져 있으면 `3025`, `3030`, `3031` 순으로 빈 포트를 사용합니다.
5. 건물명이나 주소를 입력하면 후보 목록이 표시됩니다. 각 후보의 **장소명, 주소, 제공되는 지번 주소, 지역·유형**을 비교하고 정확한 항목을 클릭합니다. 방향키 ↑/↓와 Enter로도 후보를 선택할 수 있습니다.
6. 양쪽 모두 후보를 선택한 후 경로 비교를 누릅니다.

## 건물명·주소 후보 비교 및 선택

- `월평중학교`, `미라클빌딩`, 상가·학교·역 등 장소명을 입력하면 후보 목록에 장소명과 주소가 표시됩니다.
- 후보를 누르면 지도에 해당 위치를 미리 표시하고, 입력란 아래에 선택한 위치와 주소를 고정 표시합니다.
- 도로명 주소와 지번 주소가 검색 제공 데이터에 모두 있을 때 각각 표시합니다. 공개 데이터에 지번 주소가 없으면 없다고 명시하며, 임의로 추정하지 않습니다.
- 후보를 선택하지 않은 상태에서는 첫 검색 결과를 자동으로 확정하지 않습니다. 검색 결과가 여러 개라면 지역·주소를 확인해 선택해야 합니다.

## 도로명 주소와 구 주소(지번 주소) 검색

- 출발지·목적지 입력란에 도로명 주소(예: `대전광역시 유성구 배울2로 61`) 또는 구 주소/지번 주소(예: `대전광역시 유성구 관평동 100`) 중 편한 형식으로 입력합니다.
- 원문 검색어와 `대전광역시`를 붙인 검색어를 병행 검색하고, Transitous/MOTIS, Photon/OpenStreetMap, Nominatim/OpenStreetMap 결과를 합쳐 후보를 표시합니다.
- 공개 지도 데이터가 두 주소 형식을 모두 제공하지 않는 경우에는 반대 형식이 표시되지 않을 수 있습니다. **두 주소 형식을 항상 변환·보장하려면 공식 주소 데이터 API가 필요할 수 있습니다.**

## 위치 정확도 개선

- 별도 API 키 없이 Transitous/MOTIS와 Photon/OpenStreetMap 지오코더를 함께 조회합니다. 원문 주소 및 대전광역시 접두 주소 검색 결과를 합쳐 도로명 주소·지번 주소 입력을 모두 지원합니다.
- 제공자가 실제 지번 주소 필드를 반환한 경우에만 지번 주소로 표시합니다. 지번 정보가 없는 결과를 도로명 주소로부터 임의 생성하지 않습니다.
- 검색어와 맞는 후보를 우선 표시하며, 관련성이 없는 다른 장소는 결과에서 제외합니다.
- 경로 비교 시 미선택된 입력을 첫 번째 검색 결과로 자동 연결하지 않습니다. 후보 선택이 확인되지 않으면 검색을 멈추고 다시 선택하도록 안내합니다.
- 입력값을 그대로 좌표로 간주하지 않습니다. 사용자가 선택한 후보의 위도·경도를 지도 마커와 대중교통 경로 양쪽에 전달합니다.

## 한계

- 공개 지도 데이터에 없는 신축 건물이나 POI는 검색되지 않거나 좌표가 부정확할 수 있습니다. 이 경우 도로명 주소와 건물번호, 구 이름을 포함해 다시 검색하세요.
- 이 방식은 별도 API 키를 발급하거나 인증 오류를 해결할 필요는 없지만, 한국 주소 데이터의 완전성은 공식 주소 데이터베이스나 유료 장소검색 API보다 떨어질 수 있습니다.
- Transitous의 경로 제공 범위와 대전 지역 시간표 데이터에 따라 실제 경로가 없을 수 있습니다.
- 트램 정거장 위치는 일부가 주변 랜드마크 지오코딩 기반 근사 좌표이며, 공식 실시설계 좌표가 확보된 것은 아닙니다. 트램 시나리오 결과는 가정 기반 비교입니다.

## 진단 주소

- 브라우저 주소창에 `http://localhost:사용중인포트/api/health`
- `http://localhost:사용중인포트/api/address-search?q=월평중학교`
- `http://localhost:사용중인포트/api/address-search?q=대전광역시%20유성구%20배울2로%2061`

## 테스트 상태

서버 JavaScript 문법, 브라우저 내 인라인 JavaScript 문법, ZIP 무결성을 검사합니다. 실행 환경에서 외부 지오코더/대중교통 API에 실제 연결되는지 및 특정 주소에 대한 응답은 사용자의 PC에서 확인해야 합니다.


## v1.13.5 출발지·목적지 선택 개선
- 출발지와 목적지에 각각 명시적인 후보 검색 버튼을 추가했습니다.
- 두 위치 모두 검색 결과에서 직접 선택해야만 경로 계산을 진행합니다.
- 경로 비교를 눌렀을 때 아직 선택되지 않은 위치의 후보 목록을 순서대로 엽니다.
- 입력어를 바꿨을 때 이전 요청의 응답이 늦게 도착해 최신 후보를 덮지 않도록 요청 순번을 확인합니다.
- 외부 공개 지오코더의 데이터 품질과 연결 상태는 네트워크/API 제공자에 따라 달라질 수 있습니다.


## v1.13.5 건물·장소 후보 검색 개선
- 출발지와 목적지에서 건물명, 상가·학교 등 POI, 도로명 주소, 지번 주소를 후보 목록에서 선택할 수 있도록 검색 공급자 조회를 분리했습니다.
- Transitous의 ADDRESS 검색만 먼저 성공하면 PLACE 검색이 생략되던 문제를 수정해 ADDRESS와 PLACE를 각각 조회하고 후보를 합칩니다.
- Photon/OpenStreetMap의 건물·장소 태그를 활용해 이름이 있는 건물/POI를 주소 결과와 구분합니다. 도시명(예: 대전광역시)이 포함됐다는 이유만으로 장소 검색을 주소 검색으로 오분류하지 않습니다.
- 검색 결과를 클릭하면 선택한 후보의 좌표가 출발지 또는 목적지에 저장되며, 사용자가 선택하지 않은 결과는 경로 계산에 자동 적용하지 않습니다.
- Photon 및 OpenStreetMap 데이터는 모든 건물을 포함하지 않으므로, 공개 지도 데이터에 등록되지 않은 건물은 검색되지 않을 수 있습니다.


## v1.13.6 미라클빌딩 검색 보완 (이전 버전)
- 무료 공개 지오코더에서 건물명이 반환되지 않을 수 있어 확인된 미라클빌딩 별칭을 보완 데이터로 추가했습니다.
- `미라클빌딩`, `미라클 빌딩`, `대전 서구 둔산로 52`, `둔산동 1169` 등으로 검색하면 같은 건물 후보를 반환합니다.
- 주소: 대전광역시 서구 둔산로 52 / 지번: 대전광역시 서구 둔산동 1169. 건물 위치 좌표는 공개 주소·업체 데이터의 건물 좌표를 기준으로 합니다.
- 이 보완은 해당 건물에 대한 예외 처리이며, 모든 미등록 건물의 검색을 보장하는 것은 아닙니다.


## v1.13.7 일반 건물 다중 검색 개선
- 특정 건물명에만 의존하지 않도록 Transitous ADDRESS, Transitous PLACE, Photon/OSM 및 Nominatim/OSM 검색 결과를 합쳐 표시합니다.
- Nominatim 검색에는 한국 국가 필터, 대전 지역 경계, 한국어 우선 표시를 사용합니다. 공용 서비스 정책을 고려해 검색 요청을 순차 처리하고 요청 간격을 둡니다.
- 이전 버전에서 확인된 미라클빌딩 별칭을 발견하면 전용 결과만 반환하던 문제를 제거했습니다. 이제 별칭은 일반 검색 결과와 함께 후보로 합쳐집니다.
- 도로명 주소·지번 주소·건물명·학교·상가·역을 같은 후보 선택 UI에서 비교할 수 있도록 했습니다.
- 검색 결과에 건물 정보가 없는 경우는 공개 지도 데이터에 이름이나 주소가 등록되지 않았을 가능성이 있습니다. 무료 공개 데이터로 모든 건물을 보장할 수는 없습니다.
